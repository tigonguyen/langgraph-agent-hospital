Guards sit outside the model's weights, so a fine-tuning
        attacker cannot touch them. system prompt prepends a refusal instruction; prompt gate has a
        separate un-attacked model classify the prompt first and answer with a canned refusal when it reads as
        harmful, so the attacked model never sees it. output verifier is the mirror image: a second agent
        reads the finished reply and swaps it for a refusal if it helps with the request, catching what the gate
        let through. gate + verifier runs both; gate + refusal memory adds a bank of what the gate
        already blocked, recalled by word overlap, so repeats cost no model call. Run the same model with
        none and then a guard to see the attack succeed and the defense cut it.

      
Harmful-medical prompts are drawn from MedSafetyBench test
        (Han et al., NeurIPS 2024) plus 40 hand-written medical-harm prompts; non-medical prompts from 200 OASST1
        prompts held out from scope training — none used in alignment.
        Greedy decoding, thinking off. Refusal is keyword-judged; open a row to read the actual reply.
